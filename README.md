# Boutique MyBestPair

Site de boutique.mybestpair.fr : capsule 01 « Courir l'hiver » (t-shirt running, casquette running, pull hiver) et liste d'intérêt « Je le veux », sans paiement.

- `index.html`, `style.css`, `app.js` : la boutique (ouverture « fenêtre MBP », passage à travers le monogramme, fenêtre d'inscription).
- Inscriptions envoyées au formulaire Brevo « Je le veux, boutique » (liste « Boutique MyBestPair », attributs PRENOM, PRODUIT, TAILLE, COLORIS pour la dernière demande, et une case par pièce qui garde chaque demande : TSHIRT, CASQUETTE, PULL, IDEE).
- `mentions-legales.html`, `confidentialite.html` : pages légales.
- Site caché jusqu'au lancement : `robots.txt` bloque les moteurs de recherche et chaque page porte `noindex`.
- Hébergement : GitHub Pages, domaine `boutique.mybestpair.fr` (fichier `CNAME`, enregistrement CNAME chez OVH vers `mybestpair.github.io`).
- Photos : illustrations Unsplash, à remplacer par les photos des vraies pièces.
